# JobScrapper

A job portal scraping and analytics pipeline focused on specific job fields and regions. The system collects job listings, extracts structured features from job descriptions, and presents the results through an analytical dashboard using Power BI.

## Supported Job Portals

* JobStreet
* Glints
* LinkedIn (credentials required)


## Features

* Scrape job listings from multiple job portals
* Filter jobs by specific fields, keywords, and regions
* Extract structured information from job descriptions
* Analyze required skills, technologies, experience, and other job attributes
* Store raw and processed job data
* Visualize job market trends through Power BI dashboards
